# 與 Mozc 的行為對照

T22 的數字候選與かな候選是照 Mozc 的候選形狀實作，但沒有整段移植程式。對照基準是 Mozc `src/base/number_util.cc` 與 `src/rewriter/number_rewriter.cc`；只取候選值、註解與進位門檻，不取成本、历史學習或 rerank 行為。若之後直接移植 Mozc 的 rewriter 程式或 `symbol.tsv`，必須保留 Mozc 的 BSD-3-Clause 署名（Copyright 2010-2018, Google Inc.）。

## 數字候選

以下為 `numberCandidates` 的實際輸出，與 Mozc `NumberUtil` 的 `ArabicToKanji`、`ArabicToOtherForms`、`ArabicToOtherRadixes` 對照。

| 輸入 | 本專案候選（註解） | Mozc 對照 | 備註 |
|---|---|---|---|
| `123` | `百二十三`（漢数字）、`壱百弐拾参`（大字） | 相同 | 一般漢数字省略十百千的「一」；大字保留「壱」並用「拾」 |
| `123` | `0x7b`（16進数）、`0173`（8進数）、`0b1111011`（2進数） | 相同 | 十六進位小寫並加 `0x`；八進位加前導 `0`；二進位加 `0b` |
| `12` | `十二`、`壱拾弐`、`⑫`（丸数字）、`Ⅻ`（ローマ数字(大文字)）、`ⅻ`（ローマ数字(小文字)）、`0xc`、`014`、`0b1100` | 相同 | 丸数字與羅馬數字都用 Unicode 預組合字元 |
| `0` | `零`（漢数字）、`⓪`（丸数字） | Mozc 只留一筆大字 `零` | 本專案同詞面去重後保留第一筆，因此註解是「漢数字」 |
| `10` | `十`、`壱拾`、`⑩`、`Ⅹ`、`ⅹ`、`0xa`、`012`、`0b1010` | 相同 | 大字另有 Mozc 的 `拾` 特例，本專案未列 |
| `20` | `二十`、`弐拾`、`⑳`、`0x14`、`024`、`0b10100` | 大字另有 `廿` | `廿` 是 Mozc 的追加特例，本專案未列 |
| `51` | `五十一`、`五拾壱`、`0x33`、`063`、`0b110011` | 相同 | 丸数字只到 50，因此 `51` 沒有丸数字候選 |
| `1000` | `千`、`壱阡` | 大字另有 `阡` | 本專案保留「壱阡」，不另列單字特例 |
| `10000` | `一万`、`壱萬` | 相同 | 大字使用「萬」 |
| `１２０` | `百二十`、`壱百弐拾`、`0x78`、`0170`、`0b1111000` | 相同 | 全角阿拉伯數字先轉半角再轉表記 |

### 刻意差異

- 不產生半角／全角阿拉伯數字、分隔阿拉伯數字（`1,234`）、上標、下標、`Googol`；主要轉換已提供阿拉伯數字，這些變體只會讓候選窗變吵。
- 不產生 Mozc 的 `廿`、單字 `拾`、單字 `阡` 等大字特例，只保留一般大字轉換。
- 不處理小數、負數、單位換算與日期推算。這些不在 T22 範圍；Mozc 對照也沒有顯示 T22 必須支援。
- 進位候選門檻與 Mozc 相同：十六進位 `n > 9`、八進位 `n > 7`、二進位 `n > 1`，避免 `5` 這種小數字列出無意義的進位候選。

## かな候選

Mozc 由 `VariantsRewriter` 與字體轉換處理 F6–F10；T22 只取輸出形狀：

| 操作 | 候選註解 | 範例（讀音 `きょう`） |
|---|---|---|
| F6 | ひらがな | `きょう` |
| F7 | カタカナ | `キョウ` |
| F8 | 半角カタカナ | `ｷｮｳ` |
| F9 | 全角英数 | `ａｂｃ１２３` |
| F10 | 半角英数 | `abc123` |

半角カナ的濁音使用濁點組合，例如 `がっこう` → `ｶﾞｯｺｳ`；`ヴァイオリン` → `ｳﾞｧｲｵﾘﾝ`。

## 候選排序

Mozc 的 `NumberRewriter` 會依候選類型插在主要候選附近（例如 `KANJI_FIRST` 偏移 5）。T22 不改 T12 的 N-best 排序，`Rewrite.Append` 一律把補助候選接在主要候選之後，並把分數壓在主要候選最低分之下；主要候選的順序與分數不變。

## 記号與顔文字

`data/ja/symbols` 是手動整理的四欄 TSV，沒有直接複製 Mozc 的 `symbol.tsv`。候選註解取自資料的第三欄，例如「矢印」「米印」「笑顔の顔文字」。載入與格式見 [`data/ja/symbols/README.md`](../../../data/ja/symbols/README.md)。
