# 日文記号與顔文字辭典

這個目錄是 T22 的資料檔，由 `core/ja/rewrite` 的 `LoadSymbolsFS` 讀取，供日文変換的候選視窗附加記号與顔文字。資料是手動整理，沒有直接複製 Mozc 的 `symbol.tsv`；読み與候選形狀參考常見日文 IME，行為對照與差異記在 [`core/ja/rewrite/MOZC.md`](../../../core/ja/rewrite/MOZC.md)。

## 格式

每個 `.tsv` 檔都是四欄，以 TAB 分隔，沒有表頭：

```text
読み	詞面	註解	分類
```

- 読み：查詢鍵，會轉成平假名並移除空白。同一読み可以有多筆，候選維持檔名與行號順序。
- 詞面：候選顯示與送出的字串，不可含 TAB 或換行。
- 註解：候選視窗顯示的說明，例如「矢印」「笑顔の顔文字」；不可空白。
- 分類：整理用，例如「記号」「顔文字」，目前不進入候選資料。

空行與 `#` 開頭的行會被忽略。格式錯誤會讓載入失敗，不會默默跳過。

## 檔案

- `symbols.tsv`：一般記号，依読み分組，例如 `きごう`、`やじるし`、`すうがく`、`ずけい`、`つうか`、`たんい`。
- `kaomoji.tsv`：顔文字與常見情緒詞，主要読み是 `かおもじ`，另有 `わらう`、`なく`、`おこる`、`びっくり` 等。
