# 更新說明

## 升級方式

直接執行新版的 `setup.exe`。安裝程式會保留個人詞庫，並在版本備份目錄另存一份。已經開著的應用程式要重新開啟才會換成新版。

## 目前版本的限制

- 安裝程式未簽章，屬於內部預覽版。
- 只支援 64 位元應用程式。
- 完整日文詞典與神經模型常駐時，記憶體用量可能接近 1 GB。
- Windows VM 驗收仍是 **NOT RUN**；升級與回復流程尚未在乾淨 VM 完成自動驗收。

## 回復

Windows 版由安裝收據與版本備份支援回復。若新版無法啟動，重新執行目前可用的 `setup.exe`，或依 `0c-update rollback` 的說明回到上一個版本。個人詞庫不會因回復而刪除。
