# 靈犀注音（0c）Windows 安裝說明

## 系統需求

- Windows 10 1803 以上或 Windows 11，x64。
- 目前只支援 64 位元應用程式。套件不含 32 位元的 `x86/0c_tsf.dll`，32 位元 Office、HCL Notes 等程式不會載入靈犀注音。
- 不需要 Python、numpy、onnxruntime Python 套件或 Visual C++ 可轉散發套件。產品內建原生 ONNX Runtime 與 MSVC 執行階段。

## 安裝

1. 執行 `setup.exe`。這是內部預覽版，沒有數位簽章；Windows 可能顯示「未知的發行者」或 SmartScreen 警告。
2. 允許系統管理員權限，並使用目前桌面使用者的同一個帳號完成安裝。
3. 安裝完成後不必登出。在 Windows 語言設定新增「Mixed」鍵盤：中文（台灣）→ 新增鍵盤 → Mixed。
4. 注音、日文與英文在同一個輸入法裡直接輸入。每個程式會記住上次使用的輸入法。

## 升級與移除

- 升級：直接執行新版的 `setup.exe`。個人詞庫會保留，並另存一份到版本備份。
- 已經開著的應用程式要重新開啟才會換成新版。
- 移除：Windows 設定 → 應用程式 → 已安裝的應用程式 → 靈犀注音。個人詞庫與版本備份會保留。

## 已知限制

- 這個安裝程式是未簽章的內部預覽版，尚未公開發布。
- 目前沒有 32 位元應用程式支援。
- 完整日文詞典與神經模型常駐時，記憶體用量可能接近 1 GB；一般注音使用較低。記憶體不足時，關閉模型常駐或改用統計選字。
- Windows VM 驗收仍是 **NOT RUN**。安裝、升級與回復流程仍需要在乾淨的 Windows VM 完成自動驗收。
- 日文轉換品質仍在預覽階段；模型不可用或逾時時保留統計轉換。
- Word 等其他應用程式與乾淨機仍在驗收中。

## 個人資料

個人詞庫位於 `%LOCALAPPDATA%\Zuin\user.json`。解除安裝會停用輸入法，保留個人詞庫與版本備份。
