# 隱私說明

靈犀注音（0c）在 Windows 上於本機處理輸入、候選與個人學習。產品不安裝 Python，也不內建會把輸入內容送到遠端的推論服務。

- 個人詞庫：`%LOCALAPPDATA%\Zuin\user.json`。只保存在本機，解除安裝時保留。
- 版本備份：升級時保存在本機，內含個人詞庫副本。
- 更新檢查：只有執行更新流程時才連到設定的更新來源；一般輸入不連網。
- 模型：套件內附固定版本的 ONNX 模型與原生 ONNX Runtime，推論在本機執行。
- 診斷：只有使用者主動匯出狀態摘要時才產生；內容依當時的設定與平台狀態而定。

內部預覽版仍可能有除錯輸出；回報問題前請先確認內容不含不想公開的文字。
