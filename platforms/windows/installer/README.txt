靈犀注音（0c）

安裝完成，不必登出。「靈犀注音（0c）」的單一 Mixed 設定已加入
Windows 語言設定。注音、日文與英文在同一個輸入法裡直接輸入，
不需要切換語言；清單裡沒有時，在中文（台灣）新增「Mixed」鍵盤。
每個程式會記住上次使用的輸入法。

舊版曾加入「靈犀日本語」（ja-JP）profile；升級時會自動移除，
語言清單只留一個 Mixed。升級：直接執行新版的 setup.exe，個人詞庫會保留，
並另存一份到版本備份。已經開著的應用程式要重新開啟才會換成新版。
舊版（程式名為 zuin-*）也可直接升級，已加入的鍵盤不必重新加入。
解除安裝：Windows 設定 → 應用程式 → 已安裝的應用程式 → 靈犀注音。

產品內建原生 ONNX Runtime（onnxruntime.dll 與 MSVC 執行階段），
不安裝 Python，也不需要系統的 Python、numpy 或 onnxruntime。
模型不可用時自動改用統計選字。

個人詞庫位於 %LOCALAPPDATA%\Zuin\user.json。
解除安裝會停用輸入法，保留個人詞庫與版本備份（備份內含個人詞庫副本）；
已經開著的應用程式要重新開啟才會停用，要一次清乾淨可以登出再登入。

目前為內部預覽版，尚未公開發布；Word 等其他應用程式與乾淨機仍在驗收中。
這個安裝程式沒有數位簽章，Windows 可能顯示「未知的發行者」或 SmartScreen 警告；
請只從可信任的來源取得檔案，並在執行前核對 SHA-256。

目前只支援 64 位元應用程式。套件不含 32 位元的 x86/0c_tsf.dll，
32 位元的 Office、HCL Notes 等程式不會載入靈犀注音。

完整日文詞典與神經模型常駐時，記憶體用量可能接近 1 GB；一般注音使用較低。
記憶體不足時，關閉模型常駐或改用統計選字。

Windows VM 驗收仍是 NOT RUN。這個安裝程式可安裝與使用，但尚未在乾淨的
Windows VM 完成自動驗收；回報問題時請附上安裝畫面與版本。
